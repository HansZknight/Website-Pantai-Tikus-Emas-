🐛 Troubleshooting
<details> <summary><b>🔴 Low FPS / Performance Issues</b></summary>
Solutions:
Reduce Particle Count

Settings → Performance → Reduce particles
Disable Weather Effects

Settings → Visual → Weather: OFF
Use Performance Mode

Settings → Performance Mode: ON
Close other browser tabs

Try a different browser

Chrome recommended for best performance
</details><details> <summary><b>🔇 Sound Not Working</b></summary>
Solutions:
Check browser permissions
Click the lock icon in address bar
Ensure Audio is allowed
Click anywhere on page first
Browsers require user interaction
Check the mute button
Press <kbd>M</kbd> to toggle
Check system volume
</details><details> <summary><b>📱 PWA Not Installing</b></summary>
Requirements:
Must use HTTPS
Local development: use localhost
Valid manifest.json
Check console for errors
Service worker registered
Check DevTools → Application
Try incognito mode
Extensions may interfere
</details><details> <summary><b>🎤 Voice Commands Not Working</b></summary>
Solutions:
Browser Compatibility
Chrome, Edge, Safari recommended
Firefox has limited support
Microphone Permission
Check browser permissions
Background Noise
Use in quiet environment
Speak Clearly
Natural pace, clear pronunciation
