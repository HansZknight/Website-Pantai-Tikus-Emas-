## 🐛 Troubleshooting

<details>
<summary><b>🔴 Low FPS / Performance Issues</b></summary>

<br>

### ❓ Problem
The application is running slowly or animations are choppy.

### ✅ Solutions

1. **Reduce Particle Count**
   ```
   Settings → Performance → Particle Count → Low
   ```

2. **Disable Weather Effects**
   ```
   Settings → Visual Effects → Weather → OFF
   ```

3. **Enable Performance Mode**
   ```
   Settings → Performance Mode → ON
   ```

4. **Use Lite Theme**
   ```javascript
   // In console:
   perf.setQuality('low')
   ```

5. **Close Other Tabs**
   - Browser tabs consume memory
   - Close unused applications

6. **Try Different Browser**
   - Chrome recommended for best performance
   - Firefox is also good
   - Avoid Safari for heavy animations

7. **Disable Browser Extensions**
   - Ad blockers can cause slowdowns
   - Try incognito mode

</details>

<details>
<summary><b>🔇 Sound Not Working</b></summary>

<br>

### ❓ Problem
No audio playing when it should.

### ✅ Solutions

1. **Check Browser Permissions**
   ```
   Click 🔒 in address bar → Site Settings → Sound → Allow
   ```

2. **Interact with Page First**
   - Browsers block autoplay
   - Click anywhere on the page first

3. **Check Mute Status**
   - Press <kbd>M</kbd> to toggle mute
   - Check the speaker icon in UI

4. **Verify System Volume**
   - Check OS volume settings
   - Ensure correct output device

5. **Check Console for Errors**
   ```
   Press F12 → Console → Look for audio errors
   ```

6. **Try Different Browser**

</details>

<details>
<summary><b>📱 PWA Not Installing</b></summary>

<br>

### ❓ Problem
Can't install the app to home screen.

### ✅ Requirements

1. **Must Use HTTPS**
   - PWA requires secure connection
   - localhost works for development

2. **Valid manifest.json**
   - Check DevTools → Application → Manifest
   - Look for any errors

3. **Service Worker Registered**
   - DevTools → Application → Service Workers
   - Should show "activated and running"

4. **Try Incognito Mode**
   - Extensions can interfere
   - Clear cache and try again

5. **Browser Support**
   - ✅ Chrome, Edge, Samsung Internet
   - ⚠️ Firefox (limited)
   - ⚠️ Safari (limited)

</details>

<details>
<summary><b>🎤 Voice Commands Not Working</b></summary>

<br>

### ❓ Problem
Voice recognition not responding.

### ✅ Solutions

1. **Check Browser Support**
   - ✅ Chrome (best support)
   - ✅ Edge
   - ⚠️ Safari (partial)
   - ❌ Firefox (not supported)

2. **Grant Microphone Permission**
   ```
   Click 🔒 → Site Settings → Microphone → Allow
   ```

3. **Reduce Background Noise**
   - Use in quiet environment
   - Consider using headset microphone

4. **Speak Clearly**
   - Natural pace
   - Clear pronunciation
   - Wait for beep before speaking

5. **Check Language Setting**
   ```
   Settings → Voice → Language → Select yours
   ```

</details>

<details>
<summary><b>💾 Data Not Saving</b></summary>

<br>

### ❓ Problem
Progress or settings not persisting.

### ✅ Solutions

1. **Check Storage Permission**
   - Browser may block localStorage
   - Check site settings

2. **Not in Private/Incognito Mode**
   - Private mode doesn't persist data

3. **Storage Full**
   ```javascript
   // Check storage usage
   navigator.storage.estimate().then(console.log)
   ```

4. **Export Data Regularly**
   ```
   Settings → Export Data → Save backup
   ```

5. **Clear Corrupted Data**
   ```javascript
   // ⚠️ This will reset everything
   localStorage.clear()
   ```

</details>
